# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, networking is one of the most important components of cloud infrastructure because it allows users and different cloud resources to communicate with each other. During the laboratory, I was able to see how the KillerCoda environment used a network interface and IP address. This helped me understand that even with enough computing and storage resources, a server still needs network connectivity to communicate with other systems.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing an operating system environment where applications, services, and cloud workloads can run. During this laboratory, I used Linux commands to investigate the server's CPU, memory, storage, network interfaces, IP address, hostname, and operating system. This activity helped me understand how Linux can be used to manage and inspect resources in a cloud environment.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure and its resources before deployment. In this laboratory, documenting the server information, storage, networking, cloud components, and provider comparison helped organize the information in a way that can be easily reviewed. Proper documentation can also help reduce mistakes and make troubleshooting and future maintenance easier.

## 4. What new skills did you learn during this laboratory activity?

During this laboratory, I learned how to investigate a Linux-based cloud server using terminal commands. I learned how to identify CPU, RAM, storage, mounted filesystems, network interfaces, IP addresses, and operating system information. I also practiced writing technical documentation in Markdown, comparing cloud providers, organizing evidence screenshots, and creating a basic cloud infrastructure diagram.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I was able to organize the work from this laboratory into a structured project. I added documentation for the cloud infrastructure components, a comparison of AWS, Azure, and Google Cloud, an infrastructure report based on my KillerCoda investigation, screenshots as evidence, and a cloud architecture diagram. This project helped me build practical experience with Linux, cloud infrastructure, technical documentation, and GitHub repository organization.
