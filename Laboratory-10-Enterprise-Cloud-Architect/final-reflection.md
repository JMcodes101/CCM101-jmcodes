# Laboratory 10 – Final Mission Reflection
## The Enterprise Cloud Architect

**Subject:** CCM101 – Cloud Computing  
**Project:** CloudNova Enterprise Web Portal

Laboratory 10, The Enterprise Cloud Architect, offered a chance to experience the application of various cloud computing concepts in practice. Working on this laboratory, I found out that creation of the efficient system presupposes understanding all of its elements and their operation. The most important part of this laboratory is that it allowed us to implement theoretical knowledge by creating a server environment.

One of the most fascinating elements of the activity was configuration of Ubuntu Server in Oracle VirtualBox. It gave an idea about virtualization of a server. Moreover, while configuring the virtual machine, I discovered the significance of allocating enough resources for running different applications on the server. Use of SSH for remote access was also interesting since it provided an alternative for managing servers.

While deploying the server, we used Docker Compose to run WordPress and MySQL in different containers. It helped me realize the necessity to organize application services properly. Besides, I understood the importance of Docker volumes which allow keeping application's information and thus saving data even when containers are stopped.

One more interesting part was related to implementation of security. By using UFW firewall, I came to the realization that protection of the server from unnecessary network connections is very important. Security should be maintained all the time and not just during installation of the server.

Activities related to automation and database recovery were also significant for my development. While creating a Bash script for generation of database backup files and use of Cron to schedule this process, we faced some problems. However, dealing with them helped me to develop problem-solving skills. Database recovery test also demonstrated the necessity to prepare for any problems that might occur.

The most impressive part of this project was the functioning of all the elements of our infrastructure together. This taught me that proper planning, coordination, and cooperation can make any technical task easy to accomplish.

In conclusion, Laboratory 10 was very beneficial for increasing my knowledge about cloud infrastructure and becoming more confident about performing technical tasks. I learned patience, organization, and a readiness to make mistakes in order to learn from them. I think that all these skills will come in handy both for academic tasks and in the field of IT.
