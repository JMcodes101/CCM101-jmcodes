# AWS Platform Investigation

## Platform Overview

Amazon Web Services (AWS) is a public cloud platform that allows individuals and organizations to access computing resources through the internet. Instead of purchasing physical servers, customers can rent services according to their workload and pay based on usage. AWS supports activities such as application hosting, file storage, database management, networking, security, and data processing.

## Global Infrastructure

AWS divides its infrastructure into Regions and Availability Zones. A Region is a geographic location where AWS operates cloud facilities, while an Availability Zone is an isolated group of data centers within that Region.

Organizations can distribute their applications across multiple Availability Zones to reduce service interruptions. AWS also operates edge locations that help deliver online content closer to users, improving response time and performance.

## AWS Management Console

The AWS Management Console is a browser-based dashboard used to access AWS services. It allows users to create resources, review system activity, manage security permissions, monitor expenses, and configure cloud environments.

AWS services may also be controlled through the AWS Command Line Interface, software development kits, CloudShell, and application programming interfaces. These options allow administrators and developers to automate repetitive cloud tasks.

## Four Important AWS Services

| Service    | Category              | Main Function                                                                       |
| ---------- | --------------------- | ----------------------------------------------------------------------------------- |
| Amazon EC2 | Compute               | Provides adjustable virtual servers for running operating systems and applications. |
| Amazon S3  | Storage               | Stores files, backups, website content, and other objects inside cloud buckets.     |
| Amazon VPC | Networking            | Creates an isolated virtual network where AWS resources can communicate securely.   |
| AWS IAM    | Identity and Security | Controls user identities, roles, permissions, and access to AWS resources.          |

## Advantages of AWS

1. **Flexible resource capacity:** Organizations can increase or decrease cloud resources when workload requirements change.
2. **Wide service ecosystem:** AWS offers services for infrastructure, application development, analytics, security, artificial intelligence, and other business needs.
3. **Reliable architecture options:** Resources may be distributed across different Availability Zones to improve availability and support disaster recovery.

## Enterprise Applications

AWS can support online stores that experience changing customer demand because computing resources can be adjusted during busy periods. Media organizations can use AWS to store and distribute videos, while financial institutions can use its security and monitoring services for protected workloads. Companies may also use AWS for application backup, disaster recovery, data analysis, and global website delivery.
