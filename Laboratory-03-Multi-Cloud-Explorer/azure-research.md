# Microsoft Azure Service Review

## Platform Overview

Microsoft Azure is a public cloud platform designed for building, deploying, and managing digital services. It provides computing, storage, databases, networking, security, analytics, and artificial intelligence tools. Organizations can use Azure to operate new cloud applications or transfer existing systems from local servers to the cloud.

## Global Infrastructure

Azure delivers its services through geographic Regions located in different parts of the world. Each Region contains one or more data centers connected through Microsoft’s global network.

Many Azure Regions support Availability Zones. These zones use separate facilities with independent power, cooling, and networking. An organization can place resources in multiple zones so that an application may continue operating if one location experiences a problem.

## Azure Portal

The Azure portal is an online graphical dashboard for managing Microsoft Azure resources. Through the portal, administrators can create virtual machines, configure networks, manage storage, check system performance, review costs, and control user access.

Azure also supports Cloud Shell, Azure CLI, PowerShell, software development kits, and application programming interfaces. These tools are useful for automation and for managing multiple resources efficiently.

## Four Important Azure Services

| Service                | Category              | Main Function                                                                           |
| ---------------------- | --------------------- | --------------------------------------------------------------------------------------- |
| Azure Virtual Machines | Compute               | Creates Windows or Linux virtual servers for applications and organizational workloads. |
| Azure Blob Storage     | Storage               | Stores documents, images, backups, videos, and other unstructured data.                 |
| Azure Virtual Network  | Networking            | Provides a private network for connecting and protecting Azure resources.               |
| Microsoft Entra ID     | Identity and Security | Manages accounts, authentication, application access, and organizational identities.    |

## Advantages of Microsoft Azure

1. **Microsoft product integration:** Azure works closely with Windows Server, Microsoft 365, SQL Server, and other Microsoft technologies.
2. **Hybrid cloud support:** Organizations can connect existing local infrastructure with Azure cloud resources.
3. **Centralized identity management:** Microsoft Entra ID helps administrators manage employee accounts and application permissions from one identity system.

## Enterprise Applications

Schools and universities may use Azure to manage student accounts, online learning platforms, and institutional files. Businesses using Windows Server and Microsoft 365 can connect their existing systems to Azure with less disruption. Azure may also support hospital information systems, corporate databases, remote work applications, backup services, and disaster recovery environments.
