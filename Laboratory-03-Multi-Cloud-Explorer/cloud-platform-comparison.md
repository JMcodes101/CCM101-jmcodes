## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest range because it has an extensive catalog covering infrastructure, databases, security, analytics, development, migration, and emerging technologies. Its wide selection gives organizations several options for designing specialized cloud environments.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with products such as Windows Server, Microsoft 365, SQL Server, Active Directory, and PowerShell. This makes Azure a practical option for organizations that already depend on Microsoft accounts, applications, and administrative tools.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in artificial intelligence, data analytics, and Kubernetes-based deployments. Services such as Vertex AI and Google Kubernetes Engine allow technical teams to develop intelligent applications and manage containerized workloads efficiently.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud because I am interested in data analysis, artificial intelligence, and modern application development. Its developer tools and Kubernetes services would help me explore technologies that are useful for future software and cloud projects.

## Comparison Summary

The three providers deliver similar cloud capabilities, but each platform has a different area of emphasis. AWS provides extensive service choices, Azure fits Microsoft-centered environments, and Google Cloud is attractive for data, AI, and container-based projects. A suitable provider should therefore be selected according to the organization’s existing systems, employee skills, workload requirements, and long-term objectives.
